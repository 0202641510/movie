# 대한민국 천만 관객 영화 흥행 기록 분석 앱

위키백과 '대한민국의 영화 흥행 기록' 문서에서 천만 관객 돌파 한국 영화 데이터를 수집하고 정제하여 시각화하는 Streamlit 웹 애플리케이션입니다.

## 주요 기능

- **웹 데이터 수집**: 위키백과 페이지의 HTML을 요청하여 '관객수'와 '감독' 열이 포함된 첫 번째 테이블을 자동으로 탐색합니다.
- **데이터 정제**: 각주 태그(`sup`) 제거, 영화 제목의 겹화살괄호(`《》`) 제거, 관객수 숫자 변환 및 개봉일에서 연도·월 정보를 추출합니다.
- **주요 지표 요약**: 천만 영화 총 편수, 역대 흥행 1위 영화 및 관객수를 상단 지표로 제공합니다.
- **시각화 차트**:
  - 관객수 상위 10편 가로 막대 차트
  - 개봉 연도별 천만 영화 편수 막대 차트

## 설치 및 실행 방법

1. 필요한 라이브러리를 설치합니다.
```bash
pip install -r requirements.txt
```

2. Streamlit 앱을 실행합니다.
```bash
streamlit run app.py
```
*(코드 파일 이름이 `app.py`가 아닌 경우 해당 파일명으로 변경하여 실행하세요.)*

3. 웹 브라우저가 열리면 **위키백과 데이터 가져오기** 버튼을 클릭하여 분석 결과를 확인합니다.
